Gestão de Alunos

Primeiro projeto: uma aplicação de terminal para professores gerirem alunos, disciplinas e notas. Programado em C.

Ver no GitHub
EstadoProjeto concluído
Ano2023
VersãoC / GCC

Sobre o projeto

O programa utiliza estruturas, arrays, funções e manipulação de ficheiros. Separa declarações e implementação entre funcoes.h, funcoes.c e main.c.

Funcionalidades

  • Registo e login de professores
  • Associação do professor a uma disciplina
  • Adição de alunos à turma
  • Registo e alteração de notas
  • Cálculo de médias e persistência local

Tecnologias

C GCC Structs Arrays File I/O

Desafios e aprendizagem

Modelar dados de professores e alunos em C e persistir o estado num ficheiro local, aplicando pela primeira vez uma organização modular do código.
