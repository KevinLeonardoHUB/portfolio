About the project

Commercial project developed during an internship at XPC Informática. It covers the purchasing journey and gives administrators tools to manage products, categories, services, orders and users.

Features

  • Registration, login and password recovery
  • Cart with quantity updates
  • Checkout, order creation and stock control
  • Admin panel and service requests
  • Validated image uploads

Technologies

PHP 8 HTML CSS JavaScript PHPMailer JSON

Challenges and learning

Building a complete e-commerce flow with customer/admin permissions and simple JSON persistence. The current version completes orders internally and does not integrate a payment gateway.
