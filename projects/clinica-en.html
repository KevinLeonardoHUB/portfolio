School Clinic

A web system where students create accounts, verify email and manage appointments at a school clinic.

About the project

A full-stack application organised into public pages and a PHP API. Available schedules are generated by the system, while user and appointment data is stored in MySQL.

Features

  • Student registration, login and logout
  • Email-address verification
  • Appointment booking and cancellation
  • Student appointment list
  • Schedule generation and PHPMailer emails

Technologies

PHP MySQL HTML CSS JavaScript PHPMailer XAMPP

Challenges and learning

Connecting authentication, schedules, bookings and email notifications while keeping database and SMTP credentials configurable through environment variables.
